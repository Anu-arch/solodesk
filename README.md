# SoloDesk: the back office for one person

A freelancer or tiny-shop owner usually does invoicing, chasing payments, expenses and tax dates alone. SoloDesk puts all of it in one place and works from a single typed line.

## Features
- **Quick command bar:** `invoice Rahul 5000 for logo design`, `expense 800 domain renewal`, `paid Rahul`
- **Invoices:** auto-numbered, paid / pending / overdue status, print or save as PDF
- **Payment reminders:** one-click WhatsApp message (or copy the text) with your UPI ID
- **Clients:** contact details, total billed, amount owed
- **Expenses:** categories and monthly totals
- **Dashboard:** money owed, overdue count, monthly profit, 6-month chart
- **Deadlines:** GST dates (11th and 20th) plus your own
- **Privacy:** all data stays in your browser; export and import JSON backups

## Run it
Open `index.html` in a browser. No install, no server.

## Publish (GitHub Pages)
Push this folder to a public repo, then Settings > Pages > deploy from `main`.

## Tech
HTML, CSS and vanilla JavaScript; localStorage for data.
